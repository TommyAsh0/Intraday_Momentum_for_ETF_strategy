# 指数日内动量组合策略 —— 模拟交易信号生成说明书（AI 执行版 v2.0）

> **阅读对象**：无任何项目上下文的 AI。本文档自包含——所有术语、公式、参数、边界情形均在本文定义。
> 不需要查阅任何外部资料即可完整实现本策略的模拟交易信号生成。
>
> **策略一句话**：价格开盘后在"噪声带"内的波动视为随机噪声；突破噪声带视为真实供需失衡，
> 沿突破方向开仓，日内闭合，不持仓过夜。
>
> **组合结构**：4 条腿等权，各占组合资金 25%，互相独立运行（各自独立的指标、状态机与信号）。

## 1. 术语表

| 术语 | 定义 |
|---|---|
| bar / 分钟 K 线 | 一分钟 OHLCV 行情单元，标签为**结束时间**（见 §2.2，这是最容易搞错的地方） |
| 决策时点 | 每天只有三个允许开仓的判断时刻：**10:29、11:29、13:59**（bar 结束标签） |
| 信号价 p(τ) | 标签为 τ 的 bar 的收盘价 close，即 τ 时刻刚结束那根 bar 的收盘 |
| 成交价 | 信号后**下一分钟 bar 的开盘价**（10:29 决策 → 10:30 bar 的 open 成交） |
| 噪声带 UB/LB | 由历史同日同时段波动均值构造的上下边界（§3.1），带内=噪声，带外=趋势 |
| 退出带 ExitUB/ExitLB | 仅券商腿使用：比噪声带窄（×0.7），用于止损（§3.2） |
| VWAP | 当日累计成交均价（§3.3），仅券商腿止损用 |
| armed（武装标志） | 旗舰腿专用：开仓后需价格回到带内才允许再次开仓（防止原地反复开仓） |
| 新跨越（new_cross） | 旗舰腿专用：只有价格"从带内穿到带外"才算有效入场信号 |
| 带外即入（band_state） | 券商腿：决策时点价格只要在带外即可开仓，不要求"新跨越" |
| 阶梯止盈 | 券商腿：浮盈超过阈值 stop_rate 时先平 50% 锁定利润（每趟最多一次） |
| EOD 强平 | 15:00 仍有持仓则强制平仓（不过夜） |
| 一趟（round trip） | 从开仓到完全平仓（含止盈分批）的完整持仓过程 |
| pre_close | 除息调整后的昨收价（行情源直接提供；除息日 = 昨收 − 每股分红） |

## 2. 数据需求与 bar 语义

### 2.1 每腿每日所需数据

| 数据 | 字段 | 说明 |
|---|---|---|
| 当日 1 分钟 bar | `trade_time, open, high, low, close, vol, amount` | 实时到达 |
| 历史 1 分钟 bar | 同上 | 近 20 个完整交易日（计算噪声带；旗舰腿要 20 天，券商腿要 14 天，统一备 20 天即可） |
| 日频 pre_close | 当日开盘前可得 | 除息调整口径 |
| 涨跌停价 | up_limit / down_limit | 用于封板拦截（§9.3） |

### 2.2 bar 标签语义（END 标签，务必严格照此对齐）

A 股 ETF（上交所/深交所相同）一天共 **241 根** bar：

- `09:30`：开盘集合竞价 bar（一根，O=H=L=C=竞价成交价）
- `09:31` ~ `11:30`：共 120 根，标签 τ 表示 (τ−1分钟, τ] 这一分钟
- **没有 13:00 标签**（午休）；下午为 `13:01` ~ `15:00`，共 120 根
- `15:00`：最后一根（含收盘集合竞价）

**完整标签序列**（生成规则）：
`["09:30"] + [09:31..11:30] + [13:01..15:00]`（每分钟一根，跨小时连续进位）。

**关键推论**：
- 决策时点 10:29 的信号价 = 标签 `10:29` bar 的 close（即 10:28~10:29 那一分钟）；
- 其成交价 = 标签 `10:30` bar 的 open（10:29~10:30 那一分钟的开盘）；
- 11:29 决策 → 11:30 bar open 成交；13:59 决策 → 14:00 bar open 成交。

### 2.3 当日开盘价的定义

`Open(T)` = `09:30` 竞价 bar 的 open。**例外**：若某日缺 09:30 竞价 bar（极端少见），用当日第一根有效 bar 的 open 代替。

### 2.4 时区与日历

北京时间。只在交易所开市日交易（SSE/SZSE 交易日历）；非开市日不产生任何信号。

## 3. 指标构建（盘前完成，全部用历史数据，无前视）

### 3.1 噪声带 UB/LB（每腿每日计算）

设 T 为当日，τ 为 240 个分钟价格标签之一（09:31…15:00）：

```
move(d, τ) = | Close(d, τ) / Open(d) − 1 |                     # 过去完整交易日 d 的 τ 时点相对开盘位移
σ(T, τ)    = mean( move(T-1, τ), move(T-2, τ), …, move(T-L, τ) )   # 最近 L 个完整交易日的简单均值
基准上界   BaseUp = max( Open(T), PreClose(T) )
基准下界   BaseDn = min( Open(T), PreClose(T) )
UB(T, τ)   = BaseUp × (1 + VM × σ(T, τ))
LB(T, τ)   = BaseDn × (1 − VM × σ(T, τ))
```

- **L（回看天数）：旗舰腿 L1 = 20；券商腿 L2/L3/L4 = 14**
- **VM（乘数）：L1 = 2.0；L2/L3/L4 = 1.0**
- "完整交易日"= 当天 240 个价格标签齐全的交易日；不完整日从 move 序列中剔除（不参与均值）
- **预热要求**：T 之前完整交易日数 < L → 当日该腿不交易（不输出任何信号）

**数值示例**：某日 510300 的 Open=4.000、PreClose=3.990，σ(T, 10:29)=0.40%：
- L1 腿：BaseUp=4.000，UB(10:29)=4.000×(1+2.0×0.004)=4.032；BaseDn=3.990，LB(10:29)=3.990×(1−2.0×0.004)=3.958
- 券商腿（VM=1.0）：UB=4.016，LB=3.974

### 3.2 退出带 ExitUB/ExitLB（仅券商腿，止损专用）

把噪声带按系数 0.7 收窄（入场带不变）：

```
ExitUB(T, τ) = BaseUp × (1 + 0.7 × VM × σ(T, τ))
ExitLB(T, τ) = BaseDn × (1 − 0.7 × VM × σ(T, τ))
```

（VM=1.0，即退出带宽度为入场带的 70%）

### 3.3 日内 VWAP（仅券商腿止损用）

从 09:30 竞价 bar 起累计：

```
VWAP(T, τ) = Σ_{bar≤τ} amount(bar)  /  ( Σ_{bar≤τ} vol(bar) × 100 )
```

- vol 单位为"手"，×100 转为份；零成交 bar（vol=0）不产生任何增量
- 午休无 bar，累计自然跳过；VWAP 在 13:01 延续上午累计值继续累计

### 3.4 阶梯止盈阈值 stop_rate（仅券商腿；常量，直接采用下表）

定义：标的对应指数 2017~2024 年间 |日收盘/日开盘 − 1| 的均值。**模拟盘直接使用下表固定值**：

| 腿 | 标的 | 对应指数 | stop_rate |
|---|---|---|---|
| L2 | 510500.SH | 中证500(000905.SH) | **0.895% = 0.00895** |
| L3 | 159845.SZ | 中证1000(000932.SH) | **1.049% = 0.01049** |
| L4 | 159915.SZ | 创业板指（399006.SZ) | **1.133% = 0.01133** |

（年度评审时可重算；年内保持不变）

## 5. 信号规则

### 5.1 开仓（仅 10:29 / 11:29 / 13:59 三个决策时点）

设当前持仓 pos=0（每日开盘前必为 0），p = 决策时点 bar 的 close：

**L1 旗舰腿（新跨越 + armed 机制）**：
- 维护两个布尔标志 `armed_long`、`armed_short`，每日开盘置 True
- **再武装**：在每个决策时点，若 p ≤ UB → armed_long = True；若 p ≥ LB → armed_short = True（无论是否持仓都执行）
- **开仓条件**：p > UB 且 armed_long → 开多；p < LB 且 armed_short → 开空
- 开仓成功后对应标志置 False（armed_long=False / armed_short=False）
- 含义：只有价格"从带内穿到带外"才入场；止损后价格若一直停在带外，**不入场**，直到价格先回到带内重新武装

**L2/L3/L4 券商腿（带外即入）**：
- 空仓时：p > UB → 开多；p < LB → 开空（不使用 armed 机制）

**成交**：次分钟 bar 开盘价（10:29→10:30 open 等）。

### 5.2 止损（每分钟检查）

每分钟 bar m（09:31…14:59）收盘后计算 p = close(m)，若持仓则检查止损线，触发则以**下一分钟 bar 开盘价**平仓：

| 腿 | 持多止损线 stop | 触发条件 | 持空止损线 stop | 触发条件 |
|---|---|---|---|---|
| L1 | LB(T, m) | p < stop | UB(T, m) | p > stop |
| L2/L3/L4 | min(ExitUB(T, m), VWAP(T, m)) | p < stop | max(ExitLB(T, m), VWAP(T, m)) | p > stop |

**止损只平仓、不反手**。止损后空仓，再入场须等下一决策时点（并按 §5.1 的入场规则判定）。

### 5.3 阶梯止盈（仅 L2/L3/L4，每趟最多一次）

持仓期间每分钟检查浮动收益率（相对开仓成交价）：

```
多头浮盈 = close(m) / 开仓价 − 1 ；空头浮盈 = 开仓价 / close(m) − 1
若 浮盈 > stop_rate 且本趟尚未止盈：
    立即以次分钟开盘价平掉 50% 仓位（向下取整到手）
    剩余 50% 继续按 §5.2 止损规则持有
```

### 5.4 收盘强平（EOD）

15:00 仍有残余持仓 → 强制平仓：
- L1 旗舰腿：以 `15:00` bar 的 **close** 平仓
- L2/L3/L4 券商腿：以**最后 5 分钟 VWAP** 平仓，即 14:56、14:57、14:58、14:59、15:00 五根 bar 的 Σamount/(Σvol×100)

### 5.5 触发冲突时的执行优先级

同一分钟多个条件同时触发时，严格按以下顺序：

1. 阶梯止盈（仅券商腿，先锁利润）
2. 止损平仓
3. 开仓判定（只在决策时点、且空仓时）
4. 15:00 强平（当日最后动作，凌驾一切）

## 6. 状态机（每腿独立，日内闭合）

```
FLAT ──(决策时点满足开仓条件)──> LONG 或 SHORT
LONG/SHORT ──(止损触发)──> FLAT          # 分钟级
LONG/SHORT ──(阶梯止盈)──> LONG/SHORT(半仓)   # 仅券商腿，每趟一次
LONG/SHORT(半仓) ──(止损触发)──> FLAT
任意状态 ──(15:00)──> FLAT               # 强制
```

**日终必须为 FLAT**；任何状态不隔夜、不隔日传递（armed 标志每日重置为 True）。

## 7. 仓位计算

```
腿资金 = 组合总资金 × 25%
开仓份数 shares = floor( 腿资金 / 当日开盘价 Open(T) / 100 ) × 100
若 shares ≤ 0 → 当日该腿不交易
```

阶梯止盈的平仓份数 = `floor(开仓份数 × 50% / 100) × 100`；若计算结果为 0 或等于开仓份数，则不止盈（继续持有）。

## 9. 边界情形处理

| 情形 | 处理 |
|---|---|
| 某分钟 bar 缺失 | 该分钟不动作；信号顺延到下一根有效 bar（开盘价成交） |
| 零成交 bar(vol=0) | 不产生 VWAP 增量；该 bar 不可成交（成交顺延） |
| 涨停封板（bar low ≥ 涨停价） | 买入不可成交，信号记 `BLOCKED_LIMIT_UP`；跌停镜像 `BLOCKED_LIMIT_DOWN` |
| 除息日 | 无须特判（pre_close 已含除息调整，直接用） |
| 当日缺 09:30 竞价 bar | Open(T) 用第一根有效 bar 的 open |
| 当日分钟标签不完整（缺 09:31..15:00 任一根） | 当日该腿不交易，日志记 `DATA_INCOMPLETE` |
| 数据延迟（决策时点 bar 未及时到达） | 跳过该决策时点；不得用后续 bar 回填信号 |
| 权益保护 | 任何腿当日权益 ≤ 0 → 立即停止该腿当日全部交易并告警 |

## 11. 完整一天的推演示例（L1 旗舰腿，510300）

假设：组合资金 4,000,000 元 → L1 腿资金 1,000,000 元；T 日 Open=4.000、PreClose=3.990；
σ(T,10:29)=0.40% → UB=4.032、LB=3.958（VM=2.0）。

| 时刻 | 价格事件 | 判定 |
|---|---|---|
| 09:31 | 竞价 bar 到达，Open=4.000 | 带定型：UB=4.032 / LB=3.958 |
| 10:29 | close(10:29)=4.035 > UB=4.032 且 armed_long=True | **开多信号**；armed_long→False |
| 10:30 | open(10:30)=4.036 | 成交：买入 floor(1,000,000/4.000/100)×100=250,000 份 @4.036；佣金 100.9；滑点 250.0 |
| 11:29 | close=4.020 在带内 | 再武装：armed_long=True（未持仓检查无操作；本例仍持仓中，armed 重置仅供下次） |
| 13:40 | close(13:40)=3.957 < LB(13:40)=3.958 | **止损触发**（反向带） |
| 13:41 | open(13:41)=3.956 | 平多：卖出 250,000 份 @3.956；本趟净亏 (3.956−4.036)×250,000 − 成本 ≈ −20,700 |
| 13:59 | close(13:59)=3.950 < LB(13:59)=3.957，且 armed_short=True | **开空信号** |
| 14:00 | open(14:00)=3.949 | 成交：卖出 250,000 份 @3.949 |
| 15:00 | 仍持空 | EOD 强平：买入 @ close(15:00)=3.940；当日结束，L1 腿空仓 |

券商腿同日的差异：带更窄（VM=1.0）、带外即入（无 armed）、止损线为 min(ExitUB, VWAP)、浮盈 >0.895%（L2）先平 50%、EOD 用最后 5 分钟 VWAP。

## 12. 自检清单（AI 每日落盘前逐项确认）

1. bar 标签是 END 语义（10:29 bar = 10:28~10:29）？
2. 决策只在 10:29/11:29/13:59 发生；成交都在下一分钟 bar 的 open？
3. UB/LB 用的 σ 是否只用了 T−1 及以前的完整交易日（无任何当日数据）？
